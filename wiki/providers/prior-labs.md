## Summary

Prior Labs maintains the TabPFN open-source code and offers model weights and a separately described hosted inference option; [project repository](https://github.com/PriorLabs/TabPFN).

## Key points

- Vendor-provided terms distinguish Apache-2.0 code from some separately licensed non-commercial model weights.
- Local inference and hosted service have different privacy implications; check current terms, checkpoint and location before use with security telemetry.

## Details

### Access and limits

The repository is the verified route to the software and links to model access. Hosted-service price, availability, data retention and security controls were not independently verified and must not be assumed. Research comparisons should use a pinned checkpoint and record compute and inference costs. No provider endorsement is implied.
