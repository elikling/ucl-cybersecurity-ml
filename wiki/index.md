## Summary

An evidence-led starting point for the UCL cybersecurity ML study. Start with the [landscape and comparison table](syntheses/research-landscape.md), then the [candidate study designs](syntheses/research-questions.md). Current coverage is selective, not a claim to exhaust the research literature.

## Key points

- **Challenges:** [network intrusion](challenges/network-intrusion-detection.md), [malware](challenges/malware-detection.md), [AI-assisted security analysis](challenges/ai-assisted-security-analysis.md).
- **Methods:** [anomaly detection](methods/anomaly-detection.md), [tabular foundation models](methods/tabular-foundation-models.md), [agent-assisted analytics](methods/agent-assisted-analytics.md).
- **Data:** [CIC-IDS2017](data/cic-ids2017.md), [UNSW-NB15](data/unsw-nb15.md), [EMBER](data/ember.md); [SoReL-20M](sources/sorel-20m-project.md) has an access-constrained source record.

## Details

### Software and providers

[PyOD](tools/pyod.md) for statistical baselines; [Zeek](tools/zeek.md) and [Suricata](tools/suricata.md) for network monitoring; [Sigma](tools/sigma.md) for log-detection rules. [Prior Labs](providers/prior-labs.md) maintains TabPFN software and separately licensed weights. These are candidates, not endorsements.

### Source trail

Each entity page links to a source record with an original URL, source class, access date and uncertainty. Browse the [source directory](sources/) for records. [Taxonomy](taxonomy.md) defines categories, [timeline](timeline.md) distinguishes historical captures from new developments, and the [log](log.md) records scope and outstanding checks. [README](README.md) defines wiki rules.
The [ENISA 2026](sources/enisa-threat-landscape-2026.md) and [Verizon 2026](sources/verizon-dbir-2026.md) reports inform the wider problem map but are not ML benchmarks. [MITRE ATT&CK](sources/mitre-attack-overview.md) supplies a common behaviour vocabulary.
